#### Logische Operatoren

| Bedeutung             | Eingabe in LaTeX      | Ergebnis              |
| --------------------- | --------------------- | --------------------- |
| Nicht (Negation)      | `\neg A`              | $\neg A$              |
| Und (Konjunktion)     | `A \land B`           | $A \land B$           |
| Oder (Disjunktion)    | `A \lor B`            | $A \lor B$            |
| Exklusives Oder (XOR) | `A \oplus B`          | $A \oplus B$          |
| Implikation           | `A \rightarrow B`     | $A \rightarrow B$     |
| Äquivalenz            | `A \leftrightarrow B` | $A \leftrightarrow B$ |

#### Wahrheitswerte und Vergleiche

| Bedeutung           | Eingabe in LaTeX | Ergebnis |
| ------------------- | ---------------- | -------- |
| Wahr                | `\top`           | $\top$   |
| Falsch              | `\bot`           | $\bot$   |
| Logische Äquivalenz | `\equiv`         | $\equiv$ |
| Ungleich            | `\neq`           | $\neq$   |
| Gleich              | `=`              | $=$      |

#### Quantoren

| Bedeutung         | Eingabe in LaTeX | Ergebnis   |
| ----------------- | ---------------- | ---------- |
| Für alle          | `\forall`        | $\forall$  |
| Es existiert      | `\exists`        | $\exists$  |
| Es existiert kein | `\nexists`       | $\nexists$ |

## Beispiele

| Ausdruck               | LaTeX-Code                  |
| ---------------------- | --------------------------- |
| A und nicht B          | `$A \land \neg B$`          |
| A oder B               | `$A \lor B$`                |
| A oder (A und nicht B) | `$A \lor (A \land \neg B)$` |
| Wenn A, dann B         | `$A \rightarrow B$`         |
| A genau dann, wenn B   | `$A \leftrightarrow B$`     |

## Verwendung in Obsidian

- Inline: `$A \land B$`
- Eigener Absatz:

$$
A \lor (A \land \neg B)
$$
